If you prefer step-by-step:

1. heroku login
2. heroku create your-app-name

4. heroku config:set NEXTAUTH_SECRET=$(openssl rand -base64 32)
5. heroku config:set NEXTAUTH_URL=https://your-app-name.herokuapp.com
6. git push heroku HEAD:main
7. heroku open
